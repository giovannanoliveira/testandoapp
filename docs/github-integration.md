# Integração com GitHub

O repositório oficial do Vizinhança Real é:

https://github.com/marialacerda-dot/vizinhanca-real

## Publicação

- O remoto canônico do checkout é `origin`.
- A branch de publicação é `main`.
- A conta conectada ao projeto é autorizada pelo conector GitHub do Replit; tokens e demais credenciais não são armazenados no repositório.

## Como conferir

1. Confirme o endereço configurado com `git remote get-url origin`.
2. Consulte a branch `main` no repositório para verificar o commit mais recente.
3. Para publicar mudanças pelo ambiente, use a conexão GitHub autorizada do projeto.
